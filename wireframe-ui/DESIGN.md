# Lyra（暂名）Mobile · 移动端 UI 设计规范 v4

> 本文是 Lyra 移动端（iOS / Android，Flutter 实现）的完整 UI 设计。
> 配套文件：
>
> | 文件 | 用途 |
> |---|---|
> | `prototype/index.html` | 高保真可交互原型，零依赖，双击打开。左侧目录可跳到 185 个页面/状态；「总览全部页面」平铺所有状态；手机浏览器打开自动全屏，所有手势可直接用手指操作 |
> | `tokens.json` | 设计令牌（颜色、字号、间距、圆角、尺寸、动效），与 `prototype/css/tokens.css` 一一对应 |
> | `DESIGN.md` | 本文：设计原则、组件规格、逐页布局、播放器皮肤、设置项映射、Flutter 还原指南 |
>
> 单位：逻辑像素（Flutter `dp` / iOS `pt`）。基准画布 390 × 844（iPhone 14/15），安全区：顶部 47–50，底部 34。

---

> **关于名字**：Sollin 是竞品名，原型里统一换成暂名 **Lyra**（天琴座）。App 图标也按这个名字设计：竖琴 + 织女星。确定正式名字后，把 `prototype/` 里的 `Lyra` 全局替换即可，JS 里的常量是 `APP_NAME`（`js/v4.js`）。

### v4-1 登录 / 注册 / 找回密码

- **共同外观**：环境光背景；左上角是 App 图标和名字（会漂浮），登录页用大号，注册和找回密码用紧凑版；下方是玻璃卡片，从底部升起。
- **输入框**：
  - 浮动标签：聚焦或有内容时，标签缩小上移。
  - 聚焦时显示主题色描边和外发光。
  - 校验通过显示绿色 ✓ 弹出；出错时变红、左右抖动，下方显示错误说明。
  - 密码框带显示 / 隐藏按钮。
- **登录**：「邮箱或用户 ID」+ 密码、保持登录、忘记密码 → 登录按钮（点击后文字上移消失，转圈）→「或」→ 已登录的设备扫码。
- **注册**：邮箱 + 设置密码（4 段强度条：弱 / 一般 / 较强 / 强）+ 人机验证 + 邮箱验证码（「获取验证码」需要先通过人机验证，之后 60 秒倒计时）+ 协议勾选 → 注册。成功后显示对勾描绘动画和「开始听歌」。
- **找回密码**：
  - 顶部 3 步进度：验证身份 → 重设密码 → 完成。
  - 第 1 步：邮箱 + 人机验证 + 邮箱验证码。
  - 第 2 步：新密码 ×2，带强度条、一致性对勾，并提示「其他设备需要重新登录」。
  - 第 3 步：完成，返回登录。
- **人机验证（通用组件）**：服务端决定下发哪种，组件内部切换，外部表单不用改。原型里组件右上角可以手动切换。
  - **图形字符**：扭曲字符图（点击换一张，刷新图标会旋转）+ 输入框 + 确认。
  - **滑块拼图**：拖动滑块，拼图块跟着走，提示文字渐隐。对齐（误差 7px 以内）即通过；没对齐会弹回、变红、抖动。
  - **文字点选**：提示「依次点击 夜 航 星」，点击处出现编号标记，提示里对应的字同步点亮。3 次后校验，失败自动清空。
  - 通过后整块变绿，显示「验证通过」和用时。

### v4-2 搜索

- **为什么放在底部**：单手握持时，拇指最容易够到屏幕下半部分。输入框固定在底栏上方（高 54，全圆角玻璃）；右侧是 54 的唱片圆钮，代替迷你播放条：封面旋转，外圈是主题色进度环，暂停时显示播放图标，点击打开播放器。
- **输入中**：
  - 底栏淡出下沉；输入框随键盘升起（420ms 弹簧）；右侧圆钮换成「取消」。
  - 页面变成联想列表：第一行「搜索「xx」」，后面是匹配的歌曲、歌手、专辑，再加「现场版 / 伴奏 / 翻唱」等衍生词。匹配部分高亮，右侧 ↖ 可以把这个词填进输入框继续编辑。
  - 电脑上打开原型时会显示模拟键盘；真机上用系统键盘。
- **结果页**（在搜索 Tab 内展示，不另开页面，方便直接在底部改搜索词）：
  - 顶部吸顶：类型 Tab（综合 / 歌曲 / 歌单 / 专辑 / 艺术家 / MV）+ 平台筛选（全部平台 + 5 个平台，每个带结果数）+ 相关搜索词。
  - **综合**：最佳匹配艺术家卡（带播放钮）→ 单曲 4 首（每行带来源平台徽标，关键词高亮）→ 专辑横滑（封面后面露出唱片，按下时唱片滑出并旋转）→ 歌单 → MV（16:9 卡片，带时长）→ 艺术家。
  - **歌曲**：播放全部、综合排序、只看无损。专辑和 MV 是两列网格；艺术家是带「关注」按钮的列表。
- **筛选放在搜索之后**：用户搜之前并不知道哪个平台有这首歌，所以默认「全部平台」聚合并去重，搜完再按平台和类型筛。底部输入框的占位文字会显示当前选中的平台。

## v4.1 音乐云盘（WebDAV）

> 原型：左侧目录「音乐云盘 · WebDAV」，共 29 个状态。代码在 `prototype/js/cloud.js` 和 `prototype/css/cloud.css`（在 v4.js 之后加载，覆盖 v4 的简版云盘页）。
> 取代 v3 表格里「上传到对象存储」的云盘方案：不需要 Lyra 后端，音频和备份都在用户自己的服务器上。

### 定位
- 播放用户自己的 NAS / 网盘里的音乐文件（群晖、威联通、Nextcloud、Alist、坚果云，或任何标准 WebDAV）。
- 把收藏、歌单和设置备份成 JSON，换手机后恢复。
- 不经过音乐平台和音源脚本，也不受「智能换源」影响。

### 规则
- **歌曲信息来源优先级**：文件内嵌标签 → 同目录 .lrc / cover.jpg / folder.jpg → 文件名「歌手 - 歌名」→ 音乐平台补全（可关）。文件信息面板里每项都标来源。
- **扫描**：增量扫描，只看修改时间有变化的文件夹；只用 Range 读取文件开头（ID3 / FLAC 元数据块）和结尾（M4A 的 moov）；可以暂停，下次打开继续；坚果云等有频率限制的服务默认并发 1–2。
- **不支持的格式**（APE / DSF 等）照样列出来但置灰，点了说明原因，不静默隐藏。
- **证书**：不提供「忽略所有证书错误」，只能逐台服务器信任单张证书（记住指纹）。
- **账号安全**：密码只存系统钥匙串；复制地址、日志、埋点里都不带密码。
- **缓存与下载**：边听边缓存有上限，满了先清最久没听的；「下载到本机」进下载管理，不受上限影响。离线时只能播放已缓存 / 已下载的歌。
- **备份**：内容和账号备份同一格式（桌面端可读）；恢复前自动另存一份当前数据；默认「合并」，「覆盖」用危险色按钮。
- **多服务器**：索引、缓存按服务器分开；删除服务器不动服务器上的文件，歌单和收藏里的云盘歌曲显示为「不可用」。

### 需要先定的产品问题（原型里先按括号里的做）
1. WebDAV 备份是否免费（原型没有赞助门槛）。
2. 云盘歌曲是否参与账号云同步（原型：只存在本机，不上云）。
3. 是否和「本地音乐」共用一套「文件曲目」界面（原型：本地页只放入口卡，两边列表样式一致）。

## v3 变更摘要

### 1. 智能换源：两个排序各管一件事

| | 排的是什么 | 什么时候用 |
|---|---|---|
| **解析脚本顺序** | 某一个平台内，用哪个脚本去解析，先 A 后 D 再 B | 歌曲还在同一个平台，只是当前脚本解析失败 |
| **跨平台顺序** | 平台本身，网易云 → QQ → 酷狗…… | 当前平台用所有脚本都失败后，去别的平台**搜同一首歌**（歌名 + 歌手 + 时长 ±3 秒） |

换到别的平台后，会用那个平台自己的脚本顺序去解析，所以脚本顺序是**每个平台各一份**。v2 的页面有两个问题：脚本顺序只显示了当前平台；跨平台列表里写着「N 个可用脚本」，看起来像是在给各平台排脚本，这正是你看到的混淆。v3 的改法：

- 顶部加一张流程图：① 降音质 → ② 换脚本 → ③ 换平台 → ④ 下一首，前两步标为「同一平台内」，第三步为「跨平台」。关掉的步骤会变灰。
- 页面分成「第一阶段 · 同一平台内」「第二阶段 · 跨平台」「兜底」三组。
- 脚本顺序上方有一排平台徽标，点哪个就编辑哪个平台的脚本顺序。
- 跨平台列表改为显示登录状态（已登录可以匹配会员歌曲），并且不包含当前平台。

## 1. 设计原则

1. **音乐是主角，界面是舞台。** 默认深色，表面层级靠明度区分（bg → s1 → s2 → s3），不用大面积纯色块。只在"可操作的焦点"上使用主题色：主按钮、进度、选中态、当前歌词。
2. **一个主题色贯穿全局。** 6 种主题色可切换，实时生效、无需重启。每种主题色都配有三个值：`fill`（填充）、`textOnLight`（亮色主题下的文字色，保证对比度）、`ink`（主题色上的文字）。
3. **玻璃只用在"悬浮层"。** 底栏、迷你播放条、Toast、播放器内 Sheet 用磨砂玻璃（blur 26 + saturate 1.5）；内容卡片用实底。全屏都磨砂既耗电又显脏。
4. **动效有物理感。** 位移用 `easeOut`，状态切换用弹簧（带轻微过冲）；循环动效（唱片、呼吸、声波）随暂停一起停下，恢复时从停下的位置继续。
5. **一屏一个主操作。** 每页最多一个 `btn.pri`（主题色实心）；其余操作用 `sec`（s2 底）、`ghost`（描边）或图标按钮。
6. **触控友好。** 可点区域 ≥ 44 × 44；列表行 64 高；危险操作必须二次确认（对话框）。

## 4. 全局组件规格

### 4.1 状态栏 / 顶栏

- 状态栏高 50（含刘海安全区）。浅色主题下文字深色；播放器、登录、扫码页强制白字。
- **大标题栏（Tab 页）**：上内边距 10，左 20 右 12；标题 30 / 750；右侧最多 3 个图标按钮（44 × 44），可以加一个 36 头像。

### 4.2 底部导航（5 种形态，设置 → 外观可切换）

| 形态 | 尺寸与位置 | 材质 | 指示器 | 特有行为 |
|---|---|---|---|---|
| **液态玻璃**（默认） | 悬浮，左右 14、距底 26、高 66、圆角 33 | 高透明玻璃：blur 12 + saturate 1.9 + brightness 1.08；四周 1px 内高光（上亮下暗，模拟折射边缘） | 「水滴」：56 高、全圆角，顶部径向高光 + 内阴影，自带 brightness 1.25 的背景滤镜（像放大镜一样提亮下方内容），4.2s 呼吸 | 每 7s 一道镜面高光从左扫到右；**按住可拖动水滴**，水滴放大 1.14×1.2 跟手，松手吸附到最近的 Tab |
| **浮岛** | 悬浮，左右 12、距底 28、高 64、圆角 32 | glass + blur 26 | 主题色 14% 胶囊，选中项显示「图标 + 文字」 | 支持按住拖动 |
| **胶囊** | 悬浮，左 14、右 90、高 62 + 右侧独立 62 圆形搜索钮 | glassStrong | 主题色实心胶囊 + 投影，选中项图标与文字变 ink 色 | 只放 4 项（发现 / 每日 / 音乐库 / 我的），搜索钮选中时变主题色 |

**共同的动态行为**

- **液态拉伸**：切换 Tab 时，指示器先朝目标方向拉长（38% 时刻宽度覆盖起止两项的 82%，纵向压扁到 0.84），再在目标处收拢并轻微过冲（78% 时刻 scaleY 1.06），总时长 560ms。
- **图标微动画**：每个图标的动画不同。发现：指南针转入；搜索：放大镜摆动；每日：太阳旋入；音乐库：书脊倾斜；我的：小跳。都是 500–800ms 弹簧。
- **滚动收起**（可在外观设置里关闭）：
  - 页面下滑超过 140 且仍在向下滚时，液态玻璃和浮岛收成左侧 58 的小圆钮，只显示当前 Tab 图标；迷你播放条移到同一行右侧，高 58，全圆角。
  - 经典和磨砂一体则整体下沉 30，并隐藏文字。
  - 向上滚或回到顶部 60 以内时恢复。所有尺寸变化 420ms out。
- 再次点当前 Tab：页面平滑滚回顶部，同时恢复展开态。

- **选择脚本**：✓ 动画播完 260ms 后面板收起，顶部 Toast「解析：脚本名 · 平台」。
- 平台徽标只用品牌色和单字，不使用各平台的官方 Logo。

### 4.7 反馈层

- **顶部 Toast**：距顶 56，高 ≥ 44，全圆角，深色玻璃（不随主题变）。左侧 24 圆形主题色图标。弹簧滑入，停留 1.9s 后收起。用于所有轻量反馈，不用底部 SnackBar，避免和迷你播放条打架。
- **Bottom Sheet**：顶部圆角 28，最大高度 86%。抓手 38 × 5。标题行 18 / 700 + 灰色副标题 + 右侧 ✕。上滑 380ms，收起 240ms，遮罩黑色 50%。
- **对话框**：左右 28，圆角 26，居中。顶部 56 圆形图标（accentSoft 底），标题 18 / 700，正文 14 `t2`，底部 1–2 个等宽按钮。
- **涟漪**：所有可点元素按下时，从触点扩散白色 22% 径向柔光（浅色主题为黑 10%），520ms 淡出。Flutter 用 `InkSparkle.splashFactory`。
- **回到顶部**：页面滚动超过 700 后，右下（距底 176）淡入 42 圆形玻璃按钮。
- **跑马灯**：文本超宽时无缝循环，周期 11s，每轮开头静止约 2s；两端渐隐遮罩。

### 6.1 通用骨架（所有皮肤共享）

```
状态栏（白字）
顶栏 52：⌄ 关闭 ｜ 「正在播放」11 / 来源歌单名 13.5 ｜ ··· 歌曲更多

主控制：播放模式 ｜ 上一首 34 ｜ 播放/暂停 76 白色圆钮（按下 0.9 弹性）｜ 下一首 34 ｜ 队列
辅助行：歌词 ｜ 投放 ｜ 睡眠定时 ｜ 均衡器 ｜ 皮肤（已开启的项着主题色）
```

- **背景层**（皮肤与背景 Sheet 里选）：
  - 模糊封面：封面放大 1.2 倍，blur 70 + 饱和 1.5。
  - 静态流光：3 个封面取色光斑，不动。
  - 动态流光：同上，光斑 19–24s 漂移旋转，`screen` 混合。
  - 所有背景都叠一层 8% 噪点（overlay 混合）防止色带，再叠压暗层：暗色 0–80% 可调；亮色色调为白色提亮层。
- 暂停时：封面缩小到 0.86（封面皮肤）、唱片停转、唱针抬起、呼吸和声波暂停。
- 播放器打开 460ms 从底部升起；关闭 300ms 下落。

### 9.2 关键实现提示

- **玻璃**：`ClipRRect` + `BackdropFilter(ImageFilter.blur(sigmaX: 13, sigmaY: 13))`。CSS 的 blur 26 ≈ Flutter sigma 13。饱和度提升用 `ColorFilter.matrix`，或者不做。列表滚动时注意 `BackdropFilter` 的性能：只给底栏、迷你播放条、Toast 用。
- **逐字填充**：`ShaderMask(shaderCallback: LinearGradient(stops: [p, p]))` 包裹当前行 `Text`，`blendMode: srcIn`。跨行时用 `TextPainter` 计算每行宽度，把进度换算成各行局部 stops，或者逐行套 `ShaderMask`。
- **歌词弹簧滚动**：`ScrollController` + `SpringSimulation`（stiffness 170 / damping 18）；当前行位置用 `GlobalKey` 测量。手动拖动时挂起自动跟随，4s 后恢复。
- **非当前行模糊**：`ImageFiltered(ImageFilter.blur(sigma 0.7))`。行数多时会掉帧，建议只对视口内 ±4 行生效，或者只用透明度。
- **进度条**：自绘 `GestureDetector` + `AnimatedContainer`，拖动态用 `TweenAnimationBuilder` 做轨道变粗、拇指放大。
- **跑马灯**：`marquee` 包，或者 `AnimationController` + `Transform.translate` 双份文本。
- **底栏浮岛**：`AnimatedContainer` + `Flexible(flex)`；flex 不能补间时用 `AnimatedSize` 包住文字。
- **涟漪**：`ThemeData.splashFactory = InkSparkle.splashFactory`。
- **黑胶**：`RotationTransition`；暂停时 `controller.stop()` 保持当前角度。唱针用 `AnimatedRotation`。
- **封面取色**：`palette_generator` 取主色 / 亮色，对应原型的 `coverStyle` 渐变与背景光斑。
- **亮色主题下的主题色文字**：一律用 `accent.textOnLight`，不要直接用 fill，否则对比度不足。
- **FLIP 形变**：原型里的 `data-flip` 对应 Flutter 的 `Hero`（跨路由）或同一页面内的 `AnimatedPositioned` / `AnimatedContainer`。律动皮肤的封面形变建议用 `Hero` + 自定义 `flightShuttleBuilder`，或在同一个 `Stack` 里用 `AnimatedPositioned` 改尺寸和位置。
- **瀑布歌词**：每行一个 `AnimatedSlide` / `TweenAnimationBuilder`，`Future.delayed(Duration(milliseconds: 46 * (i - k)))` 后再开始，曲线用 `Curves.elasticOut` 的弱化版或 `SpringSimulation`（stiffness 160 / damping 16）。
- **逐字填充**：每个字包一层 `ShaderMask`；有逐字时间轴（如 TTML / 逐字 LRC）时用真实时间，否则按字符数均分整行时长。
- **液态玻璃**：`BackdropFilter(blur 6) + ColorFiltered(饱和度矩阵)`，边缘高光用两层 `BoxShadow(inset)` 等价的 `DecoratedBox` + `LinearGradient` 描边。水滴指示器是第二层 `BackdropFilter` + 提亮矩阵。指示器拉伸用 `TweenSequence` 同时补间 left 和 width。
- **滚动收起底栏**：`NotificationListener<UserScrollNotification>` 判断方向，`AnimatedPositioned` 改底栏与迷你条位置。
- **左滑操作**：`flutter_slidable` 或自写 `GestureDetector` + `AnimationController`。
- **边缘返回**：iOS 自带；Android 用 `CupertinoPageRoute` 或 `PredictiveBackPageTransitionsBuilder`。
- **字母索引条**：`GestureDetector.onVerticalDragUpdate` 计算字母，配合 `ScrollablePositionedList` 跳转，并用 `HapticFeedback.selectionClick()`。

## 10. 无障碍与适配

- 文字对比度：正文 ≥ 4.5:1（`t2` 在 `bg` 上约 8:1，`t3` 只用于说明文字）。亮色主题下主题色文字使用 `textOnLight`。
- 动态字体：列表行高随字号增长（最小 64）；歌词字号独立于系统字号。
- 「减少动态效果」开启时：关闭流光、呼吸、声波环、粒子自动旋转，页面转场改为淡入淡出。
- 大屏 / 平板 / 横屏：播放器改为左右两栏（左封面 + 控制，右歌词）；列表页最大内容宽度 640 居中。
- Android 返回键：Sheet → 对话框 → 播放器 → 二级页 → Tab 首页 → 退到后台（不退出播放）。
