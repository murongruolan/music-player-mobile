## 0. v2 修了什么（"侧面看是平面"的问题）

**原因**：v1 是按"固定机位、从 +z 方向看"设计的。

- 16 事件视界：透镜弧和光子环直接画在 z = 常数的平面里，绕到侧面就变成你截图里那片竖着的"拱门"。
- 13 金缮：是一块地面平面。
- 19 光柱：10 束光都在同一个 xy 平面里。
- 17 示波器：网格是单个平面。
- 14 墨韵 / 18 神经元：厚度只有一点点，侧面看是扁的。

**修法**：

| # | v1 | v2 |
|---|---|---|
| 13 金缮 | 地面平面 | 封面贴成的**瓷球**，3D 晶格切出碎片，背面按法线压暗 |
| 14 墨韵 | 平面墨团 + 一点 z 抖动 | **3D 体积**墨团（球形分布 + 3 轴噪声 + 蘑菇状涡环），绕中心一圈分布 |
| 16 事件视界 | 透镜弧/光子环在固定平面 | 每帧用 `uCamPos` 建立观察基（rt、upv），透镜弧和光子环**始终垂直于视线**；从盘下方看时弧自动翻到下方；越接近俯视越对称；遮挡、多普勒都按真实视线计算 |
| 17 磷光示波 | 2D 李萨如 + 平面网格 | **3:2:5 三维李萨如结**，装在玻璃立方体框里，加底面刻度网格和上下移动的水平扫描面 |
| 18 神经花火 | 树突仰角只有 ±0.55 rad | 30 根树突按**斐波那契球面**全方位分布 |
| 19 雾中光柱 | 8 束光排成一排 | 10 束光**环形排布**成皇冠状，向上向外张开；地面改为极坐标同心圆 + 辐条 |
| 15 超立方 | 本来就是 3D | 不变 |

**新增 uniform `uCamPos`**：相机位置，在点云的**局部坐标系**下。

- three.js 写法：`points.worldToLocal(camera.getWorldPosition(v))`。点云对象没有变换时就等于 `camera.position`。
- 也可以直接用 three 内置的 `cameraPosition`，但它是世界坐标，点云一旦有旋转或缩放就会错，所以建议用上面的写法。

**其他通用改动**：

- 球体类预设都乘了 `facing()`（法线朝向相机的程度），背面压暗到 15–35%。加色混合下前后两面不会糊在一起，看起来更像实体球。
- 球面方向统一用 `sphDir()`（等面积采样）。`normalize(aRnd - 0.5)` 有立方体偏差，球会显得发方，v2 已全部替换。

## 2. 音频分层原则（全部预设共用）

| 层 | 信号 | 负责 | 典型量级（乘 uK 前） |
|---|---|---|---|
| 形态层 | `uBass` | 体积、半径、透视：东西"变大/变近/变亮" | 缩放 ×(1 + 0.05~0.35) |
| 姿态层 | `uMid` | 角度、扭曲、湍流、相位推进：东西"怎么动" | 角度 0.15–0.6 rad，噪声幅度 0.3–1.1 |
| 细节层 | `uTreble` | 局部闪烁、抖动、火花：只影响 1–5% 的点或边缘 | `pow(hash, 8~14) × 2.2–3.0` |
| 事件层 | `uBeat` | 每个主拍一次"事件"：闪光、波前、裂开、拧动 | 亮度 ×(1 + 1.2~2.5) |
| 整体 | `uEnergy` | 转速或亮度的微调 | ×(1 + 0.25~0.35) |

**`beatFront()`**：`uBeat` 是"峰值后指数衰减"的脉冲，`1 - uBeat/0.78` 就是"距上一拍的进度"（0→1）。
16、18、20、21、22、23、24 都用它做波前，不需要新 uniform。弱拍峰值低，波前起点会偏外，可以接受。
如果引擎能暴露 `uBeatAge`（距上一主拍的秒数），换成 `clamp(uBeatAge/0.5, 0, 1)` 更准。

**`mid` 用"相位推进"而不是"加速"**：shader 没有状态，不能积分速度。所以 `angle = t·ω + mid·k`。中频持续时会"拧"一下，中频回落时回弹。这是有意的效果，和 25 号的"咔"是同一机制。

## 3. 接入约定（给本地 agent）

1. **GLSL 位置**：搜 `// ==== PRESET nn ====`。每个预设是一个无参函数，只写 `P`（局部坐标位置）、`C`（加色颜色）、`A`（透明度）、`S`（点大小倍率）。
2. **输入沿用文档 2.x 节**：`aUv`、`aSeed`、`aRnd`、`uTime`、`uBass/uMid/uTreble/uEnergy/uBeat`、`uK = intensity × 1.6`、`uCover`。
3. **新增 uniform**：

   | 名称 | 类型 | 说明 |
   |---|---|---|
   | `uCamPos` | vec3 | 相机位置（点云局部坐标）。**v2 必需**，16、13、20、21 依赖它 |
   | `uCoverA` | vec3 | 封面平均色，提亮到亮度 ≈0.38（每首歌算一次，见 `computeCoverPalette`） |
   | `uCoverB` | vec3 | 封面最亮 15% 像素均值，提亮到 ≈0.7 |
   | `uAccent` | vec3 | `#f4d28a` |
   | `uShield` | float | 歌词区压暗强度，每个预设一个值（0.35–0.55） |
   | `uSizeK` | float | 点大小系数 = 画布像素高度 × 0.03 |
   | `uAlpha` | float | 全局透明度 0.9 |

4. **预算**：每个分支用 `// trig n` 标了累计三角函数次数，全部 ≤ 6；无循环；纹理只在 `main()` 开头采样一次。hash 和 value noise 都不用三角函数。24 号用了 `acosh`（GLSL ES 3.00 内置）。
5. **切换**：沿用 `uBurst`。`P = mix(P, P·1.6 + (aRnd-0.5)·(9,6,6), uBurst²)`，`uBurst` 以 `exp(-3.2t)` 衰减。
6. **歌词避让**：`main()` 末尾按 NDC 判断点是否落在歌词框里，命中则 `A *= 1 - uShield`。你们的歌词如果是 3D 的、跟着相机走，这段可以换成按歌词平面的屏幕投影来判断。
7. **three.js**：`three-integration.js` 里有完整示例。要点：
   - `glslVersion: THREE.GLSL3`
   - `blending: AdditiveBlending`，`depthWrite: false`
   - `points.frustumCulled = false`（顶点位置在 shader 里算，包围盒没有意义）
   - 每帧更新 `uCamPos`
8. **相机基线**（球坐标，绕 look 点；`position = look + r·(cos p·sin y, sin p, cos p·cos y)`）：

## 4. 第一批（v2 版本）

### 13 · 金缮 KINTSUGI / 封面瓷球碎裂，裂缝里是金

- **形态**：半径 2.2 的球。`y = 2·uv.y - 1`、`θ = uv.x·2π`，即等面积分布，封面按经纬贴图。
  碎片：`w = n·2.6 + (vnoise3(n·2) - 0.5)·0.9`，`cell = floor(w)`，`edge = min(fract 到各晶格面的距离)`。晶格平面与球面的交线就是裂缝，`edge < 0.045` 的点是金缝。
  **静音时**：一颗缓慢自转（0.1 rad/s）的封面瓷球，碎片各自 ±2.5% 呼吸，金网微亮。
- **运动**：自转 0.1 rad/s；碎片呼吸 `sin(0.35t + ch·2π)·0.025`；碎片沿切向晃动 0.03。
- **音频映射**：
  - bass → 碎片外浮 `+0.05·ch·uK`，并参与裂开量 `open += 0.22·bass`
  - mid → 切向晃动 `+0.15·uK`
  - treble → 金缝闪粉 `pow(hash, 10)·2.6`
  - beat → `open = (0.55·beat + 0.22·bass)·uK·0.6`，碎片沿法线外浮 `R·open·(0.12 + 0.3·ch)`。金缝留在原球面，所以每拍都会露出整张金网；金缝亮度 ×(1 + 1.6·beat)
- **配色**：碎片 = 封面像素色 ×1.5；金缝 = `#f4d28a`，闪粉 (1, 0.95, 0.8)。背面 ×0.22。
- **参考**：金缮修复的瓷器；裂纹釉。

### 14 · 墨韵 INK BLOOM / 墨在 3D 水体里晕开

- **形态**：86% 点分给 4 团墨（周期 10s，错开 2.5s），14% 是悬浮微尘。
  墨团位置绕中心一圈，水平半径 1.3–3.7，y ≈ 0.6–1.2，每个周期换一次。
  点：`dir = sphDir(rnd)`，`r0 = u^0.3`（偏向外层，形成表皮），`R = 0.35 + 1.5·√age`，再加 3 轴噪声扭曲。上半部外翻 `xz *= 1 + 0.7·age`，形成蘑菇状涡环；整体下沉 `2·age²`。
  **静音时**：墨团照常生成、翻卷、下沉、淡出。
- **音频映射**：
  - bass → 半径 ×(1 + 0.3·bass·uK)
  - mid → 湍流 `0.6 + 1.1·mid·uK`，只作用在外层
  - treble → 外层丝絮 `pow(vnoise(q·9), 3)·1.2`
  - beat → 半径 ×(1 + 0.15·beat)，新墨滴提亮 ×(1 + 0.7·beat·(1-age))
- **配色**：墨核 = 封面像素色；墨边 = mix(uCoverB, 金, 0.35) ×1.7；微尘 = mix(uCoverA, 白, 0.4)。
- **参考**：墨滴入水的高速摄影；纹影照片。

### 15 · 超立方 TESSERACT（与 v1 相同）

- **形态**：32 棱 × 约 860 点 + 16 个顶点光球。XW 0.21、YW 0.13 rad/s 旋转后做 4D→3D 透视，再绕 y 轴 0.07 rad/s。
- **音频映射**：bass → 4D 距离 `wd = 3 - 0.7·bass·uK`，内立方体胀出来；mid → XW 相位 `+0.45·mid·uK`；treble → 棱上流光 ×(0.25 + 2.2·treble)；beat → 顶点 ×(1 + 2·beat)，棱抖动 ×(1 + 4·beat)。
- **配色**：w 远 = uCoverA，w 近 = 金；顶点 = mix(金, 白, 0.4)。

### 16 · 事件视界 ACCRETION / 黑洞吸积盘，从任何角度看都成立

- **形态**：
  - 74% 吸积盘：r ∈ [1.3, 4.8]，厚度 `0.03 + 0.025·r`，开普勒自转。
  - 16% 引力透镜弧：在**垂直于视线**的平面里，半径 1.3–2.05。观察基 `V = normalize(uCamPos - O)`，`rt = normalize(ŷ × V)`，`upv = V × rt`。从盘上方看，上半弧亮、下半弧 ×0.38；从下方看则反过来；俯仰越接近 90°，两半越对称。
  - 10% 光子环：半径 1.12，同样垂直于视线。
  - 遮挡：盘上的点若 `dot(p, V) < 0`（在黑洞后方）且到视线的距离 < 1.12，则 alpha ×0.04。
  **静音时**：盘自转，螺旋密度波缓慢流动，光子环静亮。
- **运动**：`ω = 0.95·r^-1.5`；密度波 `cos(2θ - 4·ln r + 0.2t)`；多普勒 `1 + 0.6·dot(速度方向, V)`，朝相机运动的一侧更亮，任意视角都正确。
- **音频映射**：
  - bass → 内缘 `-0.12·uK`；内盘 ×(1 + 0.7·heat·bass)；透镜弧变粗；光子环 ×(1 + 0.6·bass)
  - mid → 盘厚 ×(1 + 1.4·mid·uK) + 噪声起伏；密度波对比度 ×(0.6 + 0.8·mid)
  - treble → 内盘热斑 `pow(hash, 14)·3·heat`
  - beat → 光子环 ×(1 + 2.5·beat)；亮环 `exp(-|r - 4.8·beatFront|·3)` 从内向外扫
- **配色**：白热 (1, 0.95, 0.86) → 金 → 暖橙 mix(uCoverA, (1, 0.48, 0.18), 0.55) → uCoverA ×0.55。
- **参考**：《星际穿越》Gargantua；EHT 的 M87* 照片。

### 17 · 磷光示波 PHOSPHOR SCOPE / 玻璃立方体里的三维李萨如结

- **形态**：66% 电子束：`p = H·amp·0.92·(sin(3s + δ), sin(bq·s), sin(5s - 0.7δ))`，`H = (2.4, 1.5, 2.0)`。拖尾 `tr = rnd^1.7`，`δ = 0.45t - 0.9·tr`。
  14% 立方体 12 条棱（角上更亮）；20% 底面刻度网格和水平扫描面轮廓。扫描面以 0.22 Hz 从上往下扫，电子束被扫到的位置会提亮。
- **音频映射**：bass → 振幅 `0.82 + 0.3·bass·uK`；mid → `bq = 2 + 0.3·mid·uK`，失谐后打结；treble → 3 轴抖动 + 1.5% 飞溅；beat → 余辉指数 3.2→1.5，亮度 ×(1 + 1.2·beat)。
- **配色**：束头 (1, 0.97, 0.9) → 尾 mix(uCoverB, 金, 0.3)；框和网格 = uCoverA ×0.45 + 金。

### 18 · 神经花火 NEURAL BLOOM / 全方位放电的神经元

- **形态**：10% 胞体（半径 0.4）；90% 是 30 根树突。基方向按斐波那契球面分布（黄金角 2.39996），再加 `s²` 弯曲和分叉。长度 2.0–3.8。
- **音频映射**：bass → 胞体 ×(1 + 0.3·bass·uK)，树突 ×(1 + 0.08·bass·uK)；mid → 摆动 `0.08 + 0.25·mid·uK`；treble → 末梢闪烁；beat → `exp(-|s - beatFront|·12)·2.2·beat`，一圈金光从胞体推向所有末梢。
- **配色**：树突 uCoverA ×0.85（往末梢渐暗）；电信号 金；胞体 mix(uCoverB, 金, 0.4)。

### 19 · 雾中光柱 VOLUMETRIC BEAMS / 舞台光束皇冠

- **形态**：68% 光束：10 束，发射点在地面 y=-2.2 半径 3.0 的圆上（整体 0.05 rad/s 转动），向上并向外倾斜 0.32–0.57 rad，长 8，锥形。
  20% 雾尘；12% 极坐标地网（同心圆以 0.15 Hz 向外扩散 + 16 条辐条）。
- **音频映射**：bass → 光束半径 ×(1 + 0.9·bass·uK)，地网 ×(1 + 1.2·bass)；mid → 扫动 `0.12 + 0.25·mid·uK`；treble → 雾尘闪烁；beat → 频闪 ×(1 + 2.2·beat)。
- **配色**：偶数束 mix(uCoverB, 白, 0.25)，奇数束 金；地网 uCoverB ×0.5。

### 20 · 戴森云 DYSON SWARM / 一颗恒星被文明包了起来

- **形态**（静音时同样成立）：
  - 16% 恒星：半径 0.9 的球，表面有对流噪声 `vnoise(n·4 + 0.25t)`；其中 22% 的点是日冕，向外喷 0.4。
  - 48% 卫星群：9 条轨道，半径 1.5–3.3，倾角 ±1.2 rad，升交点各不相同。卫星以 `0.9·r^-1.5` 的速度公转，相邻轨道方向相反，沿轨道成列分布（虚线状）。
  - 36% 壳层：半径 3.3 的球面，被 3D 晶格切成面板，约 50% 已建成（`ch < 0.5 + 0.15·energy`），未建成的只剩框架。壳层以 0.05 rad/s 转动，背面压暗。
- **运动**：轨道公转、轨道进动 0.03 rad/s、壳层自转 0.05 rad/s、恒星对流。
- **音频映射**：
  - bass → 恒星半径 ×(1 + 0.18·bass·uK)，亮度 ×(1.2 + 0.8·bass)；壳层半径 +0.06·uK
  - mid → 轨道进动相位 `+0.4·mid·uK`（所有轨道一起"摆"）
  - treble → 卫星反光 `pow(hash, 12)·3`；面板反光 `pow(h31(cell + t), 14)·3`；日冕喷得更远（`+1.2·treble`）
  - beat → 一道光带 `exp(-|n.y - (2·beatFront - 1)|·6)` 自下而上扫过壳层；面板按随机量外弹 `0.3·beat·ch`
  - energy → 建造进度（越响亮的段落，壳层越完整）
- **配色**：恒星 金 → 白热（按对流）；卫星 mix(uCoverA, uCoverB)；面板 uCoverA ×0.6，框架 金。
- **相机**：轨道，r = 10.5，公转 0.03 rad/s。
- **参考**：戴森球/戴森云概念图；《三体》《Stellaris》。
- **适合**：史诗电子、Synthwave、游戏原声。

### 21 · 全息地球 HOLO GLOBE / 指挥中心大屏上的地球

- **形态**：
  - 60% 地表：均匀球面点。`land = 0.65·vnoise(n·2.3) + 0.35·vnoise(n·5.1)`，`land > 0.53` 是大陆（点阵）；海洋上只保留经纬网（6 条纬线、24 条经线）；其余海洋点抬成大气层（R × 1.03–1.19），轮廓处最亮，任何角度都有一圈球形辉光。
  - 26% 数据弧：36 条，两端点在球面上，中间按 `4s(1-s)` 拱起，端点有亮点。
  - 8% 倾斜 0.45 rad 的虚线卫星环 + 3 颗卫星。
  - 6% 纬度扫描环，以 `sin(0.4t)` 上下往复。
  **静音时**：地球自转 0.08 rad/s，每条数据弧上都有一个光点游走，扫描环上下扫。
- **音频映射**：
  - bass → 大气层厚度 ×(1 + 0.6·bass·uK)、亮度 ×(0.5 + 0.6·bass)；地球半径 +5%
  - mid → 数据弧拱高 ×(1 + 0.9·mid·uK)
  - treble → 大陆上的城市灯光 `pow(hash, 10)·3`
  - beat → 36 条弧同时从起点发射脉冲 `exp(-|s - beatFront|·14)·2.5`；卫星和扫描环闪
- **配色**：大陆 mix(uCoverA, uCoverB) ×1.5；经纬网 uCoverA ×0.8 + 金 ×0.2；大气 mix(uCoverB, 白, 0.3)；数据脉冲 金；端点和卫星 白热。
- **相机**：r = 8，地球自转，相机只轻微摆动。
- **参考**：电影里的作战指挥室大屏；SpaceX 发射直播的轨道示意。
- **适合**：电子、Future Bass、科技感强的流行。

### 22 · 托卡马克 TOKAMAK / 聚变反应堆里的等离子体

- **形态**：
  - 60% 等离子体：环面，大半径 R0 = 2.3，小半径 a = 0.62。28 条磁力线分布在不同的嵌套磁面上（`rr = (0.25 + 0.75·h)·a`），沿环向角 u 绕两圈极向（`v = v0 + 2u + 流动`），截面 y 方向拉长 1.35 倍（D 形截面）。
  - 28% 环向场线圈：16 个 D 形线圈。用 `max(R0 + 0.15 + 1.05·cos v, R0 - 0.7)` 截出 D 形的直边。
  - 12% 中心螺线管：半径 0.55 的圆柱，带螺旋绕线亮纹。
  **静音时**：等离子体沿螺旋磁力线流动（每条线速度不同），线圈依次亮起（0.4 Hz 追光），螺线管绕线滚动。
- **音频映射**：
  - bass → 等离子体小半径 ×(1 + 0.3·bass·uK)，亮度 ×(1 + 0.8·bass)；螺线管 ×(1 + 1.2·bass)
  - mid → m=3 扭曲模 `rr *= 1 + 0.25·mid·uK·sin(3u + t)`，中频重时等离子体"扭"成三瓣
  - treble → 3% 的点逃逸出磁面 `pow(hash, 3)·0.9·treble·uK`，像不稳定火花
  - beat → 一团亮脉冲 `exp(-|u/2π - beatFront|·18)·2.5` 绕环跑一圈；线圈和螺线管闪
- **配色**：等离子体 mix(uCoverB, 白热, core²)；线圈 uCoverA ×0.6 + 金；螺线管 mix(uCoverA, 金, 绕线)。
- **相机**：俯视 0.5 rad，r = 9，公转 0.03 rad/s。
- **参考**：ITER / EAST 剖面图；《钢铁侠》方舟反应堆。
- **适合**：Techno、工业电子、Drum & Bass。

### 23 · 旋涡星系 SPIRAL GALAXY / 双臂旋涡星系

- **形态**：
  - 12% 核球：扁椭球（y × 0.62），半径 1.15，向中心集中。
  - 78% 盘：r ∈ [0.5, 5.3]。其中 70% 在两条对数螺旋臂上 `θ = arm·π + ln(r)·2.3 + 偏移`（偏移为三角分布，宽度随半径增加），30% 弥散分布。盘厚随半径指数变薄，并有 `0.025·r·sinθ` 的轻微翘曲。
  - 旋臂内侧是暗尘带（×0.3）；旋臂上随机散布 HII 区亮结。
  - 10% 晕：半径 2.5–8 的稀疏球壳。
  **静音时**：差速转动（`ω = 0.32/(0.5 + 0.45r)`，内快外慢），旋臂缓慢卷紧，恒星偶尔闪烁。
- **音频映射**：
  - bass → 核球半径 ×(1 + 0.15·bass·uK)、亮度 ×(1 + 0.8·bass)
  - mid → 旋臂缠绕度 `2.3 + 0.35·mid·uK`（旋臂收紧）；盘厚 ×(1 + 0.8·mid·uK)；盘亮度 ×(0.8 + 0.5·mid)
  - treble → 恒星闪烁 `pow(hash, 12)·3`
  - beat → 密度波亮环 `exp(-|r - 5.1·beatFront|·2)` 从核心向外扩散；核球 ×(1 + 0.8·beat)
- **配色**：核球 白热 → 金；旋臂年轻星 mix(uCoverB, (0.85, 0.92, 1.0), 0.4)；臂间老星 mix(金, uCoverA, 0.5) ×0.8；HII 区 mix(uCoverA, 白热, 0.5)。
- **相机**：俯视 0.6 rad，r = 10。侧面看是一张带核球的薄盘，正是真实星系的侧视形态。
- **参考**：M51 涡状星系；NGC 1300。
- **适合**：氛围、后摇、长曲。

### 24 · 虫洞 WORMHOLE / 时空嵌入图

- **形态**：
  - 58% 时空网格：悬链面 `r = b·cosh(y/b)`，喉部半径 b = 0.75，外缘 r = 5，上下各一张。网格是 14 个同心环（持续向喉部流入）加 24 条经线。
  - 30% 吸积物：沿螺旋从上方入口穿过喉部到下方出口，越靠近喉部转得越快（`φ += 2.5/r`）、越亮。
  - 6% 喉部光环。
  - 6% 背景星：半径 13–21 的球壳，相机在星空里面，任何角度都有星。
  **静音时**：网格环持续流向喉部，物质螺旋穿过，上下两张网格反向缓慢旋转。
- **运动**：网格环流入 0.25 Hz；物质沿路径 0.07×(0.7–1.3)/s；网格整体扭转 0.05 rad/s（上下反向）。
- **音频映射**：
  - bass → 喉部半径 ×(1 + 0.35·bass·uK)，整个漏斗随之呼吸；光环 ×(1.2 + bass)
  - mid → 网格扭转 `+0.8·mid·uK·(1 - rs)`，越靠近喉部扭得越厉害
  - treble → 吸积物闪烁 `pow(hash, 10)·3`；背景星闪烁
  - beat → 引力波环 `exp(-|rs - beatFront|·12)·2` 从喉部沿两张网格同时外扩；光环 ×(1 + 2·beat)
- **配色**：上网格 uCoverA ×1.3，下网格 uCoverB ×1.3；吸积物 mix(uCoverB, 白热, heat²)；光环 mix(金, 白热)；波环 金。
- **相机**：俯视 0.38 rad，r = 10，公转 0.03 rad/s。侧面看是沙漏形。
- **参考**：Flamm 抛物面 / Ellis 虫洞嵌入图；《星际穿越》虫洞。
- **适合**：电子、实验、转场感强的歌。

### 25 · 陀螺核心 GYRO CORE / 机甲或飞船的反应核

- **形态**：
  - 12% 能量核：半径 0.55 的球，表面噪声起伏。
  - 88% 是 4 层万向环：半径 1.25 / 1.75 / 2.25 / 2.75，宽 0.16。每环有随机朝向的环平面，环本身沿圆周转动（0.25–0.55 rad/s，相邻反向），同时绕自己的一条直径翻转（Rodrigues 旋转，0.3–0.69 rad/s）。环上有 6 段分段缺口、90 个刻度、一个追光。
  **静音时**：4 层环以不同速度翻转、交错，像一台在运转的陀螺仪。
- **音频映射**：
  - bass → 核心 ×(1 + 0.3·bass·uK)、亮度 ×(1 + bass)；环半径 ×(1 + 0.04·bass·uK)
  - mid → 翻转相位 `+0.6·mid·uK`
  - treble → 追光亮度 `0.3 + 3·treble`
  - beat → 翻转角 `+0.5·beat`。每拍所有环同时"咔"地多拧一下，再随 uBeat 衰减回弹，像机械卡扣；环和核心闪
- **配色**：环由内到外 uCoverA ×0.7 → uCoverB；刻度提亮 ×1.6；追光 白热；核心 mix(金, 白热)。
- **相机**：r = 8，公转 0.02 rad/s。
- **参考**：陀螺仪/万向节；《环太平洋》机甲核心；Iron Man HUD。
- **适合**：电子、硬核、节奏卡点明显的歌。

## 6. 验证清单

| 检查项 | 方法 |
|---|---|
| **任意角度都是 3D** | 预览页拖拽旋转。也可以用 URL：`?p=16&yaw=1.57&pitch=-0.1` 侧视，`&pitch=1.4` 俯视，`&pitch=-1.2` 仰视 |

| 预算 | 看 `// trig n` 注释 |

**已验证**：在无头 Chromium（SwiftShader WebGL2）中，13 个预设都能编译、渲染，没有控制台报错。每个预设都截了正面（yaw=0）和侧面（yaw=90°）对比：16 号的透镜弧和光子环在侧面同样正对相机，其余预设侧面也都有完整的 3D 体积。

**未验证**：真实 GPU 上的帧率；真实歌曲的卡点手感；在你们 three.js 引擎里的实际接入效果（`three-integration.js` 是按 three r150+ 的 API 写的，但没有在你们的项目里跑过）。
